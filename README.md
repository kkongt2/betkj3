# betkj3
### 경기 선별과 가중치 공동 탐색

가중치 자동 탐색에서 `경기 선별 + 가중치 공동 탐색`을 선택하고 목표 비율
40/50/60/80%와 시간을 지정합니다. 가중치를 고정해 8개 사전 지표의 선별 계수와
엄격도를 조정한 뒤, 선별 계수와 엄격도를 고정해 가중치를 조정하는 과정을 반복합니다.
선별 계수는 기본·무작위 초기 후보에서 시작하며, 항목별 조정과 무작위 변이로
새 조합을 탐색합니다. 각 선별 단계에서 목표 최소 선택 비율에 맞춰 엄격도를 다시
계산합니다. 가중치 단계에서도 해당 비율과 적중률 15% 조건을 만족해야 채택합니다.
선별 조건이 바뀌면 DE 후보군의 평가를 새로 시작해 서로 다른 조건의 점수가 섞이지
않게 합니다. 현재 설정 및 Runner 이전 구간의 최고 가중치·선별 계수·엄격도를
동일 선별 버전의 시작 후보로 보존합니다. 이전 v1 계수는 새 8개 지표의 계수로 재사용하지 않습니다. 기기와 Runner 모두 같은 교대 최적화 엔진을 사용합니다.
계수에는 음수도 허용하며 배당은 성과 평가에만
사용합니다. 점수는 확률이 아닙니다. 자료가 없는 말은 실제 중립 관측과 구분합니다.
목표는 전체 기간 경주 수 대비 최소 선택 비율입니다. 같은 점수는 함께 선택하므로
목표를 초과할 수 있으며 다음 연도의 실제 비율은 변할 수 있습니다.

새 선별 버전은 `joint-selection-v2`이며 기본 고정 규칙도 같은 8개 지표를 사용합니다.
기존 `joint-selection-v1` 결과는 12개 지표·계수·엄격도와 당시 계산을 유지합니다.
새 기준의 가중치를 얻으려면 공동 탐색을 다시 실행해야 합니다. 이미 실행 중인 Runner는
해당 실행의 소스 버전을 사용하므로 소급하여 새 지표로 학습하지 않습니다.

| 지표 | 산출과 계수 범위 |
| --- | --- |
| 축마와 차순위 격차 | 구매 축마와 나머지 최상위 점수 차이 · −10~10 |
| 상대마와 비구매 경쟁마 격차 | 구매 상대마 중 최저 점수와 비구매 최상위 점수 차이 · −10~10; 연승 1두는 중립 |
| 상위 3두 점수 집중도 | 상위 3두 점수 합계 비율에서 동일 점수 출전 두수 기준값을 차감 · −10~10 |
| 적정 두수 이탈 | `abs(실제 출전 두수−10)/10` · −10~0 |
| 구매마 전적·자료 신뢰도 | 과거 5경주 충실도와 활성 가중치 자료 존재율 평균 · 0~10 |
| 하위권 신예·휴양 불확실성 | 분석 5위 이하 중 전적 ≤3회 또는 180일 이상 휴양 비율 · −10~0; 전적 미확인은 불확실 처리 |
| 구매마 최근 3경주 추세 | 두수 보정 착순의 출전 순서별 기울기를 구매마 평균 · −10~10; 3경주 미만은 중립 |
| 등급·거리 구간 | 3~5등급 1300~1700m는 1, 6등급 ≤1200m는 0, 나머지·누락은 0.5 · −10~10 |

등급·거리 구간은 수익 우위가 확인된 통계가 아닌 **학습할 가설**입니다. 기본 계수는 0이며
공동 탐색에서만 조정합니다. 고정 규칙 기본 계수는 순서대로 `[2,2,1,-1,2,-1,1,0]`입니다.
계수의 부호 제한은 초기 후보·변이·재시작·입력 검증 모두에 적용합니다.
구매마는 실제 구매 조합의 고유 마필을 사용하고, 하이브리드와 박스는 1위 축마를 기준으로 합니다.
점수는 0~99로 환산하며 배당이나 실제 착순을 입력하지 않습니다. 새 보관 자료에는
경주 전 등급·거리와 과거 3경주 추세·휴양 일수만 추가합니다. 이전 보관 자료에서
추가 항목이 없으면 추세·구간은 중립이며, 모든 자료 재생성 후 새 항목을 사용할 수 있습니다.

과거 전체 탐색 결과와 시간 순서 검증은 별개입니다. 후자는 초기 2개 연도 이후
매년 이전 자료만으로 가중치, 선별 계수와 점수 기준을 선정하고 다음 연도에 고정
적용합니다. 현재/저장한 사용자 가중치는 이 검증의 후보에 포함하지 않습니다.
검증 후보는 기본 가중치에서 시작하고 각 학습 기간의 성과만으로 교대 최적화합니다.
검증 연도의 결과는 탐색이 끝난 후 성적 계산에만 사용합니다.
기존 기본 지표 설계까지 독립인 전향적 실험은 아니며,
현재 최고 조합 자체의 미관측 성과를 입증하지 않습니다.

적용·저장은 가중치와 선별 모델을 함께 보존합니다. 경기 선별 기본값은 OFF이고
적용할 때도 ON/OFF 상태를 바꾸지 않습니다. OFF에서는 후보의 선별 글씨를 숨깁니다.
엄격도를 조절하면 적용 시의 목표 비율에서 달라질 수 있습니다. 가중치 또는 순위를
직접 변경하면 이전 공동 탐색 선별 모델을 해제하고 기본 모델로 돌아갑니다.

### Worst quarter 필수 하한

안정성 반영에서 기존 분기 감점 기준과 별도로 필수 하한을 켤 수 있습니다. 입력 기본값은
1.05배이며 기존 요청과의 호환성을 위해 새 옵션은 기본 OFF입니다. 둘 다 1.05로 설정하면
통과 후보는 추가 분기 감점 없이 전체 환급배수로 경쟁합니다. 최근 8개 분기 중 선택·평가
30경주 이상인 유효 분기가 2개 이상이어야 하며, 이들 최저 환급배수가 하한 미만이거나
표본이 부족하면 최종 후보·후보군에서 제외합니다. 배당 상한을 적용한 탐색용 환급배수
기준이며, 학습 기간의 조건입니다. 후속 연도나 미래 성과에 대한 보장은 아닙니다.

미달 후보도 DE 탐색을 유도하는 데 사용할 수 있지만 최고 결과로 채택하지 않습니다.
조건 충족 후보가 없으면 결과 적용을 비활성화하고 '조건 충족 후보 없음'을 표시합니다.
기기·Runner·병렬 결과 병합·저장/검산에 같은 기준을 사용합니다. 이전 결과에 새 하한을
소급 적용하지 않으며, 새 Runner 요청에서 `fitness.worstFloor`로 보존합니다.
