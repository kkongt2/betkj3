# 비선형 모델 시간 순서 실험

이번 실험에서는 실전 모델을 교체하지 않았습니다. 2024년부터 2026년 9월 20일까지
2,833경주의 시간 순서 평가에서 새 모델 모두 환급 배수 1.0 미만이었고,
기존 가중치·선별 연구 최고값 0.8711도 넘지 못했습니다.

| 모델 | 실제 선택 비율 | 적중률 | 평균 적중배당 | 적중률 × 평균배당 |
|---|---:|---:|---:|---:|
| 선형 로지스틱 비교 모델 | 100.00% | 29.51% | 2.799 | 0.8259 |
| CatBoost: 기존 지표·결측·자료 개수 | 100.00% | 26.47% | 2.756 | 0.7297 |
| CatBoost: 추세·전개 등 92개 입력 | 100.00% | 29.12% | 2.702 | 0.7868 |
| 두 말의 동반 입상 직접 예측 | 100.00% | 28.10% | 2.678 | 0.7523 |
| 동반 입상 모델 + 이전 미학습 예측으로 선별 (목표 60%) | 60.82% | 33.84% | 2.403 | 0.8130 |

목표 40%인 조합 선별은 실제로 39.11%만 선택해 최소 40% 조건에 미달했습니다.
목표 60% 결과는 모든 평가 연도에서 실제 선택 비율 40% 이상입니다.
적중률이 높아져도 평균 적중배당이 낮아지면 환급 성과가 개선되지 않았습니다.

## 검증 설계

- 전체 자료: 2022년 이후 확정 4,840경주, 50,652개 말 출전 기록.
- 2023년은 선별 모델용 과거 미학습 예측을 만드는 기간으로 사용합니다.
- 주 평가: 2024년, 2025년, 2026년(9월 20일까지), 총 2,833경주.
- 각 평가 연도 이전 자료로만 말·조합 모델을 학습합니다.
- 깊이 3/4 및 학습 회수는 이전 연도 하반기의 분류 로그 손실로 선택합니다.
- 선별 모델은 이전 연도까지 쌓인 미학습 예측을 입력으로 사용합니다.
  선별 학습과 직전 6개월 기준 선택도 분리합니다.
- 선별 순위 후보는 적중 확률, 기본 점수 대비 차이, 기본 확신도 세 가지입니다.
  목표 40/60/80%의 점수 기준과 순위 방식은 직전 검증 기간만으로 정합니다.
- 확정 지급배당은 과거 성과 계산과 과거 검증 기간의 선별 규칙 평가에만 사용합니다.
  말·조합·선별 분류기의 입력 및 학습 목표에는 지급배당을 넣지 않습니다.
- 조합 모델은 개선된 말 모델의 분석 1위 축마를 유지하며, 2~10위 상대 후보를 비교합니다.
- 같은 경주의 모든 조합을 같은 날짜 구간에 배정하고 경주별 총 학습 가중치를 동일하게 둡니다.
- 선택된 경주만으로 적중률·평균 적중배당을 계산합니다. 연도별 숫자도 JSON에 보존했습니다.

## 입력과 누락 자료

기존 17개 지표를 고정 전체기간 정규화 값 대신 당시의 원자료로 재계산했습니다.
지표 존재 여부와 전적 개수, 나이·성별·부담중량·거리 변화, 최근 5경주의
착순 보정값·기록·초반 위치·후반 기록의 평균/기울기/변동성/최근값을 추가했습니다.
말 이름 및 개인 식별자는 학습 입력이 아니며 이전 전적을 연결하는 데만 씁니다.
현재 경주의 착순·기록 및 같은 날 다른 경주 결과는 입력 생성 후에만 이력에 넣습니다.
같은 날의 결과를 보지 않는 날짜 단위 갱신을 사용합니다.

상세 결과 자료가 없는 19경주는 기존 출전표 정보로 입력을 구성하고 평가에도 포함했습니다.
누락된 상세 결과는 만들어 넣지 않았으며 이후 상세 기록 집계에는 반영하지 않습니다.
해당 목록은 `ml-report.json`에 있습니다. 빈 지표는 NaN과 별도 존재 표시로 처리합니다.

이는 과거 재검증이며 아직 관측하지 않은 미래 실전 검증은 아닙니다.
여러 방법을 비교한 결과이므로 가장 높은 숫자만으로 일반화를 입증하지 않습니다.

## 재실행

이 실험 브랜치의 자료를 사용합니다. 원본 보고서는 다음 커밋으로 고정했습니다.

- 저장소: `kkongt2/timeline`
- 커밋: `058af7036a54fa1b98952d58bbf1f3992b1cc1c9`
- 파일: `training/history-v7.jsonl.gz`
- Git blob SHA: `ada1569775cd3e2d20e17f455e7e86c18abedac0`

```bash
python -m pip install -r research/requirements.txt
curl -L --fail https://raw.githubusercontent.com/kkongt2/timeline/058af7036a54fa1b98952d58bbf1f3992b1cc1c9/training/history-v7.jsonl.gz -o /tmp/betkj3-source-v7.jsonl.gz
python scripts/ml-experiment.py --source /tmp/betkj3-source-v7.jsonl.gz --out /tmp/betkj3-ml-research
python scripts/ml-walkforward.py --data /tmp/betkj3-ml-research --stage all
node tests/ml-research.cjs /tmp/betkj3-ml-research
```

생성되는 `report.json`은 통계와 학습 시점, `predictions.json`은 경주별 사전 모델의
선택 결과, `selection-members.json`은 선별된 경주 목록입니다.
`.cbm` 모델과 입력 배열도 출력 폴더에 저장됩니다.
독립 집계 검사는 공식 지급배당을 다시 대조하고, 학습 시점·선택 비율·중복 경주를 확인합니다.
운영 앱·기존 가중치·사용자 설정은 변경하지 않습니다.
